# assets

Screenshots of the platform actually running, kept in this repo because it's
public — the docs that use them live in `platform-docs` and reference them by
raw URL.

| file | what it shows |
|---|---|
| `backstage-create.png` | the template list in the portal |
| `backstage-catalog.png` | a scaffolded service registered in the catalog |
| `argocd-tree.png` | argocd's resource tree for a service it discovered on its own |
| `grafana-dashboard.png` | the dashboard that appears without anyone creating it |
| `alert-firing.png` | `ServiceDown` firing for real, annotation rendered with the service's own name |

All real runs, not mockups. To link one from anywhere:

```
https://raw.githubusercontent.com/efekaya-devops/backstage-idp/main/assets/<file>
```
